# Decompilación / sources

El repositorio contiene el source del mod. Loom también puede preparar los sources/decompilados de Minecraft para desarrollo.

```bash
./gradlew genSources
```

Para compilar:

```bash
./gradlew build
```

El proyecto puede abrirse directamente como Gradle en IntelliJ IDEA. La carpeta `.github/workflows` compila el proyecto automáticamente en GitHub Actions.
